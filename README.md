 Unidad 2: Arquitectura y Lenguaje Web

 Descripción
Repositorio académico que contiene las actividades prácticas de JavaScript correspondientes a la Unidad 2 de Arquitectura y Lenguaje Web.

 Contenido
- **Actividad 1:** Variables y tipos de datos.
- **Actividad 2:** Ciclos y manejo de inventario.
- **Actividad 3:** Condicionales y operadores.
- **Actividad 4:** Métodos de arreglos, funciones flecha, manejo de errores y manipulación del DOM.
- **Actividad 5:** Clases, herencia, encapsulamiento y polimorfismo.
- **Diagrama UML:** Representación de las clases de la actividad 5.

 Tecnologías utilizadas
- JavaScript
- HTML
- Visual Studio Code
- Node.js
